# Excel関数学習機能 仕様案

状態: SUM・IFの最初の試作に必要な基本仕様は合意済み。
全対象関数の網羅性とカテゴリ分けは公式出題範囲との照合が必要。
具体的な問題・画面遷移・確認項目は[操作例](function-practice-examples.md)を参照する。
最新の見直しでは、未完成の問題は途中の選び直しにかかわらず全て破棄し、確定済みの回答記録を変更しない。
通常モードは、選び直しを含めて選択直後に判定する従来仕様を維持することを確認済み。

現在地: 実装前レビュー。合意済みの仕様と実装方針を確認してから、実装に進む。

仕様確認は5項目ずつ行い、それぞれに推奨案を添える。
ユーザーの回答を受けるまでは、推奨案を確定事項として扱わない。

## 目的

MOS試験対策用のスマートフォン向けWebアプリの1機能として、Excelの関数を学習する。
関数名だけでなく、表と問題文から必要な引数を選べるようにする。

## カテゴリの分類基準

- Excel 365のスペシャリスト・エキスパート両試験の公式出題範囲に明記された関数を比較する。
- 両方に明記された関数は「スペシャリスト・エキスパート共通」とする。
- 片方だけに明記された関数は、その試験の専用カテゴリとする。
- これはアプリ内の分類基準であり、公式がこの3カテゴリの関数一覧を提供していると確認したものではない。
- 個々の関数の振り分けは、実際の公式資料と照合して確定する。

## 出題方法

- 関数を指定して練習: 対象関数から選び、その関数の問題を繰り返し解く。
- 対象カテゴリからランダム出題: 対象カテゴリに属する関数の問題を混ぜて解く。

どちらの出題方法でも、通常モードとハードモードを選べる。
1セット5問とする。

- 初期対象の「スペシャリスト」「共通」を個別にON/OFFでき、初期状態は両方ONとする。
- 選択したカテゴリに属する関数を、指定練習・ランダム出題の対象とする。
- ランダム出題は、対象関数が5種類以上ならセット内で同じ関数を出さない。
- 対象が5種類未満なら、対象関数を一巡してから再出題する。
- 同じ関数を繰り返す場合も、表と正解の引数を変える。

開始画面でカテゴリ・出題方法・モードを選ぶ。
初回は両カテゴリON・通常モードとし、次回から前回の設定を引き継ぐ。
設定を引き継ぐデータは、関数ごとの4状態の回答記録とは別に保持する。

## 引数の個数

- 初版では、各関数の出題パターンごとに使う引数の個数を定める。
- 省略可能な引数を使うパターンも用意し、そのパターンで必要な数だけ順に選ぶ。
- 初版では、回答者が自由に引数を追加・省略する操作は設けない。
- ハードモードで正解と異なる関数を選んだ場合も、選んだ関数に用意した出題パターンの個数に従う。
- 引数名・構文一覧などのヒントをハードモードに追加しない。

## 学習モード

| 項目 | 通常モード（初期状態） | ハードモード |
| --- | --- | --- |
| 引数を選ぶときの説明 | Excelで表示される引数の意味を表示 | 引数名・意味・構文一覧を非表示 |
| 回答の流れ | 関数から各引数へ順に選択（原則6択、例外あり） | 同左 |
| 採点 | 選択直後に判定。誤答なら同じ段階で選び直す | 式完成後に「答え合わせ」で一括採点 |
| 途中の誤答表示 | 「不正解」のみ | 関数・引数とも正誤を表示しない |
| 解説のタイミング | 式完成後、または「答えを見る」を押したとき | 提出して採点した後、または「答えを見る」を押したとき |

通常モードの説明は、日本語版Excel 365の引数説明に沿った内容とする。
正確な引数名と説明文は、各関数を追加する際に確認する。
この資料の「合計する範囲」などの説明は表示例であり、Excelの文言を確認して転記したものではない。

ハードモードでは組み立て中の式と「第1引数」のような現在の段階を表示する。
引数名・意味の説明・構文一覧は表示しない。問題文、表、選択肢は表示する。
セット開始前にモードを選び、セット中は固定する。
開始画面で選択でき、次回の学習には前回の設定を引き継ぐ。

## 採点と回答後の解説

- 計算結果だけでは正解にせず、問題の条件に合う関数・引数・記号を選べているかで判断する。
- 問題と候補は正解が一意になるように用意する。問題の条件を満たす別解を誤答として出さないことも生成時に確認する。
- ハードモードでは、決められた回答段階を選び終えれば、等号・カンマ・括弧・引用符が誤っていても提出できる。
- 記号が正しいかどうかで提出ボタンの有効・無効を変えない。誤りは提出後に採点し、不正解として説明する。
- 回答後は、正解の式・計算結果・関数の役割・各引数の意味を短く表示する。
- 記号を間違えた場合は、その違いも説明する。
- 解説は通常モードの式完成後、ハードモードの提出後、または「答えを見る」を使った後に表示する。
- 通常モードの途中の誤答表示と、ハードモードの途中のヒントは増やさない。

## 最小限の回答記録

長期的に保持する回答記録は次の4状態に整理する。

- 未回答
- 不正解（通常モードで途中に間違えた場合も同じ扱い）
- 正解
- 2連続正解

以前の「初回正解」「解き直しで正解」「答えを見た」という個別の記録分類は、この4状態に置き換える。
記録は関数×通常／ハードごとに、現在の状態だけを保持する。
過去100セットの問題・回答・解説を保存する案は採用しない。
更新するのは出題対象の関数の状態とする。
例えばSUMの問題でAVERAGEを選んで不正解になった場合はSUMを更新し、AVERAGEの記録は変更しない。

関数一覧には4状態のラベルを表示する。
通常／ハードを切り替えて、それぞれのモードの状態を確認できるようにする。

状態の遷移は次のとおり。同じ関数・同じモードの1問ごとの結果だけで判定する。
間に別の関数の問題が入っても、その関数の連続は維持する。

| 現在の状態 | 次の1問が正解 | 次の1問が不正解、または答えを見た |
| --- | --- | --- |
| 未回答 | 正解 | 不正解 |
| 不正解 | 正解 | 不正解 |
| 正解 | 2連続正解 | 不正解 |
| 2連続正解 | 2連続正解 | 不正解 |

通常モードでは、一度でも途中の選択を間違えた問題は、選び直して式を完成しても不正解と同じ扱いにする。
未完成問題を「新しく始める」で破棄する場合は、不正解として確定せず、保存済みの成績を変更しない。
ハードモードでは、途中の選び直しは正誤に影響せず、提出した式で判定する。
不正解の提出後も正解の式と解説を表示して、その問題を終了する。
ハードモードでは1問につき提出は1回とする。

「答えを見る」は両モードで利用でき、式完成・提出前に正解の式と解説を確認できる。
使った場合は不正解として記録し、連続正解をリセットする。専用の記録項目は追加しない。

成績は使っている端末のブラウザに保存し、初版はログイン不要とする。端末間同期は後から検討する。
提出ごとに記録を更新して保存し、アプリを閉じても保持する。
1問の結果は、通常モードでは式完成時、ハードモードでは「答え合わせ」を押した時に確定し、即保存する。
「答えを見る」を使った場合は、その時点で1問を不正解として確定し、即保存する。
途中の選択は再開用に都度保存し、アプリを閉じただけでは成績を変えない。
同じ1問の結果を、再読み込みや画面の再表示によって二重に反映しない。
通常モードで途中に間違えた事実は再開用データに保持し、式完成時に不正解として確定する。
「新しく始める」で未完成問題を破棄しても、その問題の結果を成績へ反映しない。
すでに確定した問題の結果は保持し、二重に反映しない。

## 学習途中の自動保存と再開

- 回答と進行状況を自動保存する。
- 画面を閉じたり再読み込みした後も、同じ問題・同じ回答段階から再開できる。
- 再開時は問題文・表・選択済みの関数と引数・モード・成績に関わる途中状態を復元する。
- 復元時に問題を新しく生成したり、通常モードの誤答履歴を消したりしない。
- 再開用の途中データは、長期的に保持する4状態の回答記録と区別する。
- 閉じるときの処理だけに頼らず、回答の提出時に記録を保存する。

## 再開と新規開始

- 中断したセットがあれば、開始画面に「続きから」「新しく始める」を用意する。
- 「続きから」は保存した問題・回答段階・選択内容・途中の誤答の有無を復元する。
- 「新しく始める」は確定済みの回答記録を保持し、新しい条件でセットを開始できる。
- 通常・ハードとも、未完成の現在の問題は全て破棄する。
- 途中の選び直しがあっても、未完成問題を破棄するだけなら関数の状態を変更しない。
- すでに提出・採点して確定した問題の結果は保持する。
- アプリを閉じるだけでは破棄や新規開始にならず、成績を変えずに再開できる。

## 保存失敗時の動作

- 保存できなかったことを画面に表示し、現在の回答を保持する。
- 再試行できるようにし、保存完了までは次の問題に進めない。
- 採点済みの結果の保存に失敗している場合は、その保存を完了してから新しいセットへ進む。未完成問題の破棄とは区別する。
- 再試行によって同じ1問の結果を二重に反映しない。

## 5問終了後の結果画面

- セット内の正解数を「5問中○問」の形で表示する。通常モードで途中に間違えた問題は、不正解として数える。
- 各問題の正誤を表示する。
- 各問題の正解の式と解説を確認できるようにする。

## 回答の修正

- 組み立て中の式の関数・引数をタップすると、その部分の選択肢へ戻って選び直せる。
- 「戻る」ボタンでも一つ前の回答段階へ戻れる。
- 第1引数から戻る場合は関数選択へ、第2引数以降から戻る場合は一つ前の引数選択へ戻る。
- 関数を変更した場合は選択済みの引数をすべてクリアし、新しく選んだ関数に対応する引数を選び直す。
- タップ・「戻る」で前の段階へ移動するだけなら、選択済みの入力を保持する。
- 前の引数の値を変更した場合は、それより後の引数をクリアし、順に選び直す。
- タップ・「戻る」は通常モードの回答中も利用できる。
- 通常モードでは選び直しも即時に判定し、途中で誤答した事実を戻る操作で消さない。
- ハードモードでは提出前の選び直しで正誤を示さず、提出した式で判定する。

## 1問の学習体験

1. 問題文と表を読む。
2. 6択から関数を選ぶ。
3. 選んだ関数と現在の回答段階を表示する。通常モードでは現在選ぶ引数の意味も表示する。
4. 各引数を順に選ぶ。原則6択とし、自然な候補が少ない引数は2〜5択とする。
5. 通常モードでは必要な引数が正解で揃うと解説へ進む。ハードモードでは式完成後に「答え合わせ」で採点し、解説へ進む。
6. 「次の問題」で、異なる表・引数の問題に進む。

学習中は組み立て中の式と現在の段階を表示する。
`=SUM(` を選択済みなら、その文字列と現在の段階を表示する。
通常モードでは「第1引数: 合計する範囲」、ハードモードでは「第1引数」とする。
未選択の引数を示す表示は式の文字として扱わず、まだ選んでいない閉じ括弧などを補わない。
等号・カンマ・括弧・文字列の引用符を自動で付けず、選択肢に含めて選ぶ。
関数・引数と記号を一緒に選び、カンマの有無や等号・括弧・引用符の違いも候補に含める。
記号を含む選択の例: `=IF(` → `B2>=60,` → `"合格",` → `"不合格")`。

通常モードでは、正解なら次の選択段階へ進み、誤答なら現在の段階に留まって選び直す。
誤答時に追加する表示は「不正解」のみとし、正解の選択肢や誤りの理由は表示しない。
通常モードでは、もともと表示している引数の意味を引き続き表示する。
すべての段階で正解を選び、式が完成した後に、完成した式・計算結果・解説を表示する。

ハードモードでは、途中の関数・引数の選択・変更時に正誤を表示しない。
正誤によらず先へ進め、選んだ関数に対応する引数の選択肢を表示する。
式を完成させた後に「答え合わせ」で提出し、一括採点する。
提出前はタップ・「戻る」で修正でき、提出後は正誤と正解の式・解説を確認する。

## スマートフォンでの表示

- スマートフォンの縦向き表示を基準に、問題・表を上半分、回答操作を下半分に配置する。
- スマートフォン縦向きの6択は2列×3行とし、長い選択肢は折り返して全文を読めるようにする。
- 原則6択とし、TRUE/FALSEなど自然な候補が少ない引数は2〜5択で表示する。
- Excelのセル参照を読み取れるよう、表に列記号と行番号を付ける。
- 関数選択時と引数選択時で、下半分の選択肢を入れ替える。
- 表は原則データ3〜5行・2〜4列とする。
- 収まらない表は上半分の中でスクロールし、下半分の回答操作を表示したままにする。
- セル参照は相対参照を扱い、絶対参照・複合参照とコピー先に応じた参照の問題は後から追加する。
- 文字サイズ拡大時も、問題と選択肢を読んで回答できることを実画面で確認する。

- 初版はオンラインで開くスマートフォン向けWebアプリとする。
- オフラインでの新規起動や、ホーム画面への追加を前提とした対応は後から検討する。
- 保存済みの回答記録はアプリを閉じても保持する。

## 操作例: SUMで合計する

問題文: 「全商品の売上の合計を求めてください。」

|   | A | B | C |
| --- | --- | --- | --- |
| 1 | 商品 | 売上 | 個数 |
| 2 | ノート | 1200 | 3 |
| 3 | ペン | 800 | 4 |
| 4 | ファイル | 1500 | 2 |

完成した式は `=SUM(B2:B4)`、計算結果は `3500`。
この例では関数選択で `=SUM(`、最後の引数選択で `B2:B4)` を選んで式を完成させる。
誤答候補には関数や範囲の違いだけでなく、等号・括弧の欠落や不要なカンマなどの違いも含める。
複数の引数が必要な問題では、引数1の後に引数2以降の選択へ進む。

## 問題を毎回変える方法

最初は、関数ごとに学習目的を定めた問題の型を用意し、その型の中で表と正解を一緒に生成する。
問題文だけ、あるいは数字だけを独立に変えるのではなく、問題文・表・正解・解説が一致するようにする。

変化させる内容:

- 商品名などの項目とセルの値。
- データの行数や列の配置。それに合わせて正解となる参照範囲も変える。
- 条件を扱う関数では、比較対象と条件値。
- 選択肢の並び順。

生成する問題の条件:

- 各段階は原則6択とし、自然な候補が少ない引数のみ2〜5択とする。重複を防ぎ、正しい回答経路では各段階に正解を含める。
- 問題の条件を満たす正解が複数同時に候補へ入らないようにする。
- 誤答候補は、範囲の端の取り違えや列の取り違えなど、学習上意味のあるものにする。
- 未定義の計算、意図しないエラー、表の外を参照する正解を作らない。
- 同じ関数が続く場合も、表と少なくとも一つの正解引数を変える。
- 同じセット内では、同じ問題を出さない。
- 選択肢の並び順は問題生成時に決め、同じ回答条件での選び直し・戻る・再開では保持する。
- 前の引数を変更して候補の内容が変わる場合は、変更後の条件に対応する候補を生成する。
- 表は原則データ3〜5行・2〜4列とし、数値の範囲は各関数の学習目的に合わせる。

## 最初の実装単位

SUMとIFで次を一通り使える状態にする。

- 問題文と表を表示する。
- 関数と引数を原則6択で選ぶ。自然な候補が少ない引数は2〜5択とする。
- 通常モードでは選択ごとに正誤を判定し、誤答なら同じ段階で選び直す。
- ハードモードでは途中の正誤を表示せず、選んだ関数に対応する引数を選択し、式完成後に一括採点する。
- ハードモードでタップ・「戻る」によって回答を修正できる。
- 完成した式、結果、解説を確認する。
- 「答えを見る」で正解を確認でき、その問題を不正解として記録する。
- 5問で1セットを完了する。
- 次の問題で表と正解の引数が変わることを確認する。

試作した関数で操作を試してから、合意したスペシャリスト・共通の対象範囲へ広げる。
初版は1問1関数とし、入れ子は後から追加する。
使う引数の個数は各関数の出題パターンで定め、省略可能な引数を使うパターンも用意する。
誤答候補として別の関数を提示する場合も、その関数の引数選択を用意し、ハードモードで最後まで回答できるようにする。
